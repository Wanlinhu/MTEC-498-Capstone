# References and Resources

## Suggested by Prof. van Troyer (Sep 11, 2026)

- **Reactable / reacTIVision**: tabletop music instrument that tracks fiducial markers from below the table. reacTIVision is its open-source tracking software and sends TUIO (OSC) messages.
  - https://reactivision.sourceforge.net/
  - https://github.com/mkalten/reacTIVision
- **Audio d-touch** (Costanza, Shelley, Robinson, 2003): music interface using a webcam and physical blocks.
  - https://www.semanticscholar.org/paper/INTRODUCING-AUDIO-D-TOUCH:-A-TANGIBLE-USER-FOR-AND-Costanza-Shelley/c61959c04e1a3ae65fd1a5b77a15746a9790051a
- **BrickMusicTable** (Waldhör, Hödl, Reichl, 2024): LEGO-brick sequencer read by a top-down camera using brick color, size, and position.
  - https://dl.acm.org/doi/10.1145/3701571.3701592

His advice: start with a small OpenCV prototype (a top-down camera reading 2–3 colors and positions), and simplify the tracking as much as possible while keeping the interaction idea.

## Sand-Based Interfaces

- **SandScape** (MIT Tangible Media Group): reads sand shape from light shining through a layer of beads from below.
  - http://web.mit.edu/ebj/www/Clay-Sand_BTTJ04.pdf
- **AR Sound Sandbox**: shaping kinetic sand creates ambient soundscapes.
  - https://mirevi.de/blog/ar-sound-sandbox/
- **Sand Noise Device**: generative music from sand shape and lit objects in a sandbox.
  - https://www.vice.com/en/article/sand-noise-device-fuses-augmented-reality-and-generative-synths/

## Sandplay

- **Supporting sandtray therapy on an interactive tabletop** (CHI 2010): a virtual sand tray designed with sandtray therapists. Reference for a possible future direction.
  - https://dl.acm.org/doi/10.1145/1753326.1753651
